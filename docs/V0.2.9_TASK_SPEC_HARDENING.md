# v0.2.9 — Task Specification & Prompt Reliability Hardening

This candidate evolves the reconstructed v0.2.8 baseline without introducing new top-level agents.

## Promoted mechanisms

- composable `PROMPT_SPEC_v1` instead of mutually exclusive prompt types;
- explicit `TASK_MODE` separation for generation, exploration, selection, planning, execution, validation and repair;
- minimum-change task-state merge for follow-up deltas;
- material ambiguity resolution policy;
- solvability assessment before solution generation;
- constraint-conflict detection;
- demonstration conditioning based on representative coverage rather than fixed example counts;
- `ROLE != CAPABILITY != AUTHORITY`;
- verifiable rationale instead of private chain-of-thought output requirements;
- divergent ideation with deduplication before convergence;
- production prompts require evals, fixtures and versioning;
- duplicate content does not count as independent evidence.

## Regression status

GitHub Actions executes `compileall`, unit regression tests and JSON-contract validation on this branch and on pull requests to main.

Historical v0.2.8 counts remain targets only; they were not reconstructed byte-for-byte and are not claimed as freshly reproduced.
