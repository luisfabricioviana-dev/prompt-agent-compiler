# v0.2.10 — Runtime State Machine and Artifact Registry

Status: **WAVE 9 CANDIDATE / STACKED ON EXECUTION GRAPH PR #15**

## ArtifactRegistry

Artifacts are now runtime records bound to ArtifactContract identity.

Properties:

- SHA-256 digest;
- byte size;
- declared producer binding;
- monotonically increasing in-process sequence;
- idempotent re-registration of identical bytes;
- fail-closed conflicting rewrite;
- rejection of undeclared artifacts;
- atomic node-output preflight before any record is written.

A node that declares output artifacts cannot pass until every declared output is
present and contract-valid.

## RuntimeStateMachine

Node states:

- PENDING
- READY
- RUNNING
- PASS
- FAIL
- BLOCKED

Only root nodes start READY. Dependents become READY only after all
prerequisites PASS.

A node may complete only from RUNNING. Artifact recording happens before the
PASS transition; registry failure leaves the node RUNNING and leaves
dependents unchanged.

A causal node failure marks the node FAIL and recursively BLOCKS downstream
nodes.

The runtime refuses to initialize unless ExecutionSpecV2 readiness is READY.

## Scope limit

The registry and state machine are deterministic in-process components. This
wave does not claim durable external persistence, distributed locking, crash
recovery, or multi-worker consensus.
