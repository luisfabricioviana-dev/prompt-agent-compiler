# v0.2.10 — Packaging and Contract Coverage Gate

Status: **WAVE 10 CANDIDATE / STACKED ON RUNTIME STATE PR #16**

## Packaging

The v0.2.10 runtime contracts now have PEP 517/621 package metadata:

- distribution: `prompt-agent-compiler`;
- version: `0.2.10`;
- Python: `>=3.11`;
- installable namespace: `contracts*`;
- recovered v0.2.9 tree explicitly excluded from the distribution.

CI builds and installs the package with no runtime dependencies, then changes
working directory to `/tmp` and imports canonical runtime modules. This proves
imports are coming from the installed distribution rather than the checkout.

The build backend dependency itself is not presented as a locked reproducible
toolchain in this wave.

## Coverage gate

The project intentionally avoids adding a new third-party test dependency in
this wave.

`tools/run_contract_coverage_gate.py` uses the Python stdlib `trace` module
for executed lines and AST statement lines as the denominator.

Metric name:

`stdlib_trace_ast_statement_line_proxy`

This is a deterministic coverage proxy and must not be described as
coverage.py line coverage.

Observed baseline in Full project regression run #70:

- 153 tests PASS;
- package install PASS;
- package smoke import PASS;
- contract statement-line proxy: **87.6%**.

The blocking CI minimum is set to **85%**, leaving limited headroom while
preventing large untested runtime additions.

## Regression

Recovered public-safe v0.2.9 remains a separate green job and is not included
inside the installable v0.2.10 distribution.
